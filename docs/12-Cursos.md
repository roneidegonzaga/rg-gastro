# PRD 12 — Cursos

Versão: 1.0
Status: Aprovado

---

# Objetivo

O módulo Cursos é responsável por gerenciar todo o ciclo de vida dos produtos educacionais da empresa.

Seu objetivo é organizar a criação, atualização e manutenção dos cursos, centralizando processos, materiais, documentos e histórico de versões.

Este módulo gerencia o produto.

O módulo Vendas e Alunos gerencia quem comprou o produto.

---

# Objetivos do Módulo

O módulo deverá permitir.

- cadastrar cursos
- controlar produção
- controlar atualizações
- organizar materiais
- gerenciar documentos
- acompanhar processos
- acompanhar checklists
- controlar versões
- centralizar links
- integrar com certificados
- integrar com vendas
