# Inteligência Artificial

A IA faz parte da plataforma.

Ela deverá atuar como assistente operacional.

Nunca poderá.

Excluir dados.

Modificar registros automaticamente.

Executar ações críticas sem confirmação.

Toda recomendação da IA deverá ser explicável ao usuário.

---

# Objetivo Final

O objetivo deste projeto é construir uma plataforma única capaz de administrar toda a operação da RG Gastrô.

No futuro, essa mesma arquitetura deverá permitir evolução para um produto SaaS, sem necessidade de reconstrução da base existente.

Toda decisão tomada durante o desenvolvimento deverá considerar esse objetivo de longo prazo.

---

# Última Regra

Se existir qualquer dúvida entre implementar rapidamente ou implementar corretamente.

Escolha implementar corretamente.

A qualidade da arquitetura tem prioridade sobre a velocidade de desenvolvimento.
