# PRD 20 — Equipe

Versão: 1.0
Status: Aprovado

---

# Objetivo

O módulo Equipe é responsável por gerenciar todas as pessoas que participam da operação da empresa.

Seu objetivo é centralizar informações, responsabilidades, permissões, produtividade e carga de trabalho de cada colaborador.

Este módulo não tem como finalidade realizar gestão de RH.

Seu foco é a operação da empresa.

---

# Objetivos do Módulo

O módulo deverá permitir.

- cadastrar colaboradores
- controlar permissões
- acompanhar produtividade
- distribuir responsabilidades
- acompanhar carga de trabalho
- visualizar indicadores
- integrar tarefas
- integrar agenda
