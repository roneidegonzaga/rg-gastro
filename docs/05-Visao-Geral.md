# PRD 05 — Visão Geral

Versão: 2.0
Status: Aprovado

---

# Objetivo

A Visão Geral é o Cockpit Executivo do Painel RG Gastrô.

Seu objetivo é apresentar, em uma única tela, tudo o que é mais importante para a tomada de decisão da empresa.

Ao abrir o sistema, o usuário deverá conseguir compreender o estado da operação em menos de um minuto, sem precisar navegar entre módulos.

A Visão Geral não substitui os dashboards específicos dos módulos.

Ela consolida apenas as informações mais relevantes de cada área da empresa.

---

# Objetivos do Módulo

A Visão Geral deverá permitir responder rapidamente.

• Como está minha empresa hoje?

• Estou batendo minhas metas?

• Como está meu caixa?

• Tenho clientes que precisam de atenção?

• Tenho mentorados parados?

• Existem tarefas atrasadas?

• Tenho compromissos hoje?

• O marketing está performando?

• Alguma área exige ação imediata?

# Alertas Inteligentes

Criar uma área exclusiva acima dos widgets.

O objetivo é chamar atenção apenas para informações relevantes.

Exemplos.

"3 contratos encerram nos próximos 15 dias."

"5 tarefas estão atrasadas."

"Você possui 2 reuniões hoje."

"O faturamento está 18% abaixo da meta."

"Existem 4 follow-ups vencidos."

"O CMV de dois clientes piorou este mês."

"Você ainda não publicou conteúdo esta semana."

Nunca exibir alertas desnecessários.

Mostrar apenas aquilo que exige ação.

# Widget Inteligência Artificial

Criar um widget exclusivo.

Esse widget deverá funcionar como um resumo executivo da IA.

Exemplo.

"Seu faturamento cresceu 14% em relação ao mês passado."

"Você possui três clientes prontos para renovação."

"Seu melhor conteúdo foi um Reels publicado há oito dias."

"Há dois mentorados sem sessões há mais de vinte dias."

"Sua campanha X apresenta queda no ROAS."

O objetivo é reduzir a necessidade de análise manual.

# Permissões

Administradores.

Visualizam todos os widgets.

Equipe.

Visualiza apenas widgets dos módulos autorizados.

Widgets sem permissão não deverão aparecer.

---

# Responsividade

No desktop.

Widgets organizados em grid.

No tablet.

Grid adaptativo.

No celular.

Widgets empilhados verticalmente.

Nenhuma informação deverá ser removida.

---

# Critérios de Aceite

O módulo será considerado concluído quando.

✓ funcionar como Cockpit Executivo da empresa

✓ responder aos filtros globais

✓ possuir KPIs clicáveis

✓ possuir alertas inteligentes

✓ possuir widgets independentes

✓ permitir personalização dos widgets

✓ possuir pesquisa global

✓ possuir atalhos rápidos

✓ possuir Timeline Executiva

✓ possuir widget exclusivo da IA

✓ integrar informações de todos os módulos

✓ respeitar permissões por usuário

✓ atualizar automaticamente após alterações

✓ funcionar em desktop, tablet e mobile
