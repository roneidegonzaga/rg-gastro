# PRD 11 — Mentorados

Versão: 1.0
Status: Aprovado

---

# Objetivo

O módulo Mentorados é responsável por toda a gestão dos programas de mentoria da empresa.

Seu objetivo é centralizar o acompanhamento de cada mentorado durante toda sua jornada, permitindo visualizar evolução, resultados, tarefas, sessões, processos e provas sociais em um único ambiente.

Mais do que controlar encontros, este módulo deverá demonstrar claramente a transformação alcançada pelo mentorado.

---

# Objetivos do Módulo

O módulo deverá permitir.

- gerenciar mentorados
- controlar sessões
- acompanhar evolução
- registrar tarefas
- aplicar processos
- gerar checklists
- registrar resultados
- acompanhar indicadores da mentoria
- organizar provas sociais
- alimentar dashboards
