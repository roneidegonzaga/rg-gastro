# PRD 18 — Projetos e Tarefas

Versão: 1.0
Status: Aprovado

---

# Objetivo

O módulo Projetos e Tarefas é responsável por centralizar toda a execução operacional da empresa.

Seu objetivo é substituir checklists isolados, anotações e controles externos, reunindo em um único ambiente todas as tarefas provenientes dos demais módulos do sistema.

Este módulo será o centro operacional da empresa.

Nenhuma tarefa deverá existir apenas dentro de outro módulo.

Sempre que um módulo gerar uma tarefa, ela deverá aparecer automaticamente aqui.

---

# Objetivos do Módulo

O módulo deverá permitir.

- gerenciar projetos
- gerenciar tarefas
- acompanhar execução
- controlar prioridades
- controlar responsáveis
- visualizar calendário
- acompanhar produtividade
- integrar todos os módulos

O módulo será considerado concluído quando.

✓ permitir cadastro de projetos

✓ permitir cadastro de tarefas

✓ gerar tarefas automaticamente pelos demais módulos

✓ possuir Dashboard

✓ possuir Kanban

✓ possuir Calendário

✓ responder aos filtros

✓ integrar com Agenda

✓ integrar com Clientes

✓ integrar com Mentorados

✓ integrar com Cursos

✓ integrar com CRM

✓ integrar com Processos

✓ manter Timeline

✓ integrar com IA

✓ funcionar em desktop e mobile
